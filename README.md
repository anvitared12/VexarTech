# Driver Dashboard

A dashboard designed to analyze **driver performance, experience, and risk indicators**.

### Key Analysis

* Driver license/experience analysis
* Identification of unusual or high-risk driver behavior
* Driver performance indicators and flag levels
* Comparison of drivers based on relevant metrics
* Visual summaries using charts and KPIs

### Objective

The dashboard helps identify **drivers who may require attention, training, or further evaluation** based on data-driven thresholds.

Deployment Link : https://vexartech.onrender.com/


# Vehicle Dashboard

A dashboard designed to monitor **vehicle performance, riding behavior, and abnormal sensor readings**.

### Key Analysis

* Accelerometer and gyroscope analysis
* Detection of abnormal vehicle movement
* Identification of high-risk riding patterns
* Sensor-based flagging using statistical thresholds
* Visual summaries of vehicle performance and alerts

### Objective

The dashboard helps identify **unusual vehicle behavior and potential risk conditions** using sensor data and statistical analysis.

Deployment Link : https://vexartech-1.onrender.com/
